# Background images

Положи сюда фоновые изображения сайта.

Рекомендуемые имена файлов:
- `hero-bg.jpg` — главный фон первого экрана
- `gallery-bg.jpg` — фон секции галереи
- `moon-bg.png` — декоративная луна или текстура

Файлы можно будет подключать в `index.html` по путям `backgrounds/имя-файла`.
